# विप्लव संग नम्रता | 10 दिसंबर 2026

Mobile-first interactive wedding invitation website featuring pure CSS/vanilla JS animations, romantic background music, interactive itinerary timeline, RSVP form, and photo gallery.

## Features
- **Opening Interactive Envelope**: Unfolds with smooth video and audio transition into the sacred garden archway.
- **Hero Stagger Animations**: "विप्लव", "संग", and "नम्रता" with handwritten-style reveals and date badge.
- **Two-Day Wedding Itinerary**: Day 1 & Day 2 interactive tabs with animated drawing vine timeline.
- **Complete Details**: Shloka, Our Story, Venue directions, Dress code palette, Countdown timer, and RSVP.
- **Music Player**: Floating audio toggle with soft looping background playback.
- **Lightweight 60fps Animations**: Hardware-accelerated transitions respecting `prefers-reduced-motion`.

## Deployment
This repository is configured for direct deployment on **GitHub Pages**:
- Via **GitHub Actions**: `.github/workflows/deploy.yml` automatically deploys the `/dist` site on pushes to `main`.
- Or via **Branch Deployment**: Root `index.html` redirects automatically to `/dist`.
